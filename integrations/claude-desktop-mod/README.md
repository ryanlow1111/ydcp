# YDCP link — a mod for the Claude desktop app

A small mod (plugin) for the **Code** tab of the Claude desktop app. It tells your YDCP companion what Claude is doing, so she **cheers when a reply is done**.

## What it does

It writes one small local file, `~/.ydcp/state.json` (Windows: `%USERPROFILE%\.ydcp\state.json`):

| When | It writes |
|---|---|
| Claude starts working on your message | `{"mood":"working"}` |
| Claude finishes its reply | `{"mood":"done"}` → she cheers |
| The turn ends with an error | `{"mood":"failed"}` |
| You stop it, or it declines | `{"mood":"idle"}` |

Nothing is sent anywhere. If YDCP was never installed (no `~/.ydcp` folder), it writes nothing. The source is one short file: [`hooks/register.ts`](hooks/register.ts).

## Install

1. In YDCP, turn the link on: **Menu → React to agent → On**. It's off by default.
2. Copy this folder (`integrations/claude-desktop-mod`) somewhere permanent, for example `~/.claude/mods/ydcp-link`.
3. Add that folder to `CLAUDE_CODE_PLUGIN_DIRS` in your Claude settings file, `~/.claude/settings.json` (Windows: `%USERPROFILE%\.claude\settings.json`):
   ```json
   {
     "env": {
       "CLAUDE_CODE_PLUGIN_DIRS": "/Users/you/.claude/mods/ydcp-link"
     }
   }
   ```
   If you already list other mods there, add this path to the list (separated by `:` on macOS).
4. Start a new Claude session. Send a message; when the reply finishes, she cheers.

**Prefer something simpler?** The [Claude Code hooks](../claude-code-hooks/) do the same job with a few lines in your settings. They also work in the terminal version of Claude Code.

## Develop

With the Claude CLI:

```bash
claude plugin validate .
claude plugin test .
```

The `.claude-plugin/types/` folder is generated by the CLI and isn't committed.
