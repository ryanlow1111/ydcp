# YDCP + Claude desktop mod

> 🚧 Coming in v0.1 (milestone M4).

A mod for the Claude desktop app's Code tab. It writes `~/.ydcp/state.json` as Claude works, so your companion can react: she cheers when a reply finishes and gets sleepy when things are quiet.

It's ported from the prototype that drove the first version of the companion inside Claude's browser pane. Until it lands, the [Claude Code hooks](../claude-code-hooks/) do the same job and also work in the desktop app.
